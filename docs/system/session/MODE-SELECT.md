# [ MODE SELECT ]

## [ OVERVIEW ]

Prints the mode recorded in `/run/ph4ntxm/mode`.

## [ STARTUP ]

Used by callers that need the current session mode as a single text value.

## [ RUNTIME ]

Prints the existing mode file's contents. If the file is absent, prints `linux`.
