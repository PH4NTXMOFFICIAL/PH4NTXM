# [ IDENTITY TRAY ]

## [ OVERVIEW ]

Provides the Identity indicator in the system tray.

## [ STARTUP ]

Starts as a GTK application indicator in the desktop session.

## [ RUNTIME ]

Show Identity launches the viewer as a child process with its own lifetime.  
Quit ends the indicator's GTK loop.
