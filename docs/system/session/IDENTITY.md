# [ IDENTITY ]

## [ OVERVIEW ]

Displays the current PH4NTXM session identity.

## [ STARTUP ]

Runs when the operator opens the Identity viewer directly or from its tray entry.

## [ RUNTIME ]

Reads the generated mode and identity state for the operator's identity view.  
Presents the session's generated identity values and provides access to the Health report for the detailed runtime assessment.
