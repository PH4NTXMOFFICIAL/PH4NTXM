# [ PANIC BUTTON TRAY ]

## [ OVERVIEW ]

Provides the Panic Button tray entry.

## [ STARTUP ]

Runs as the desktop's Panic status icon.

## [ RUNTIME ]

The menu opens the activation window and tracks its child PID to avoid duplicate windows.  
The icon changes while that child is open and resets when it exits.
