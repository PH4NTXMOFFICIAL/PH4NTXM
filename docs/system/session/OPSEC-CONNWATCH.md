# [ OPSEC CONNWATCH ]

## [ OVERVIEW ]

Displays the ConnWatch monitor's runtime status and observations.

## [ STARTUP ]

Runs as the operator's terminal interface for the ConnWatch service.

## [ RUNTIME ]

Repeatedly reads the monitoring service's status and runtime statistics.  
Refreshes the terminal view with current inbound activity and monitor state so the operator can inspect the recorded observations.
