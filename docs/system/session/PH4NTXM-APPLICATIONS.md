# [ APPLICATION GUIDE ]

## [ OVERVIEW ]

Provides the operator's controls and runtime views for the live session.

## [ STARTUP ]

Boot Pilot opens automatically. The remaining controls are available through their installed desktop launchers and tray entries.

## [ RUNTIME ]

Boot Pilot displays readiness and Wi-Fi controls. Continue closes it; the browser button launches the selected browser after protection checks.  
Identity displays the generated persona. Health presents the categorized runtime report.  
Lockdown enables full network containment or restores the selected profile. Panic requests emergency termination after operator activation. USB Removal Nuke arms or disarms the storage-removal trigger.  
Controls report failed helper requests. The separate OpSec Suite presents detailed diagnostic observations.
