# [ BOOT PILOT ]

## [ OVERVIEW ]

Opens automatically at desktop startup to show protection readiness and provide Wi-Fi controls.

## [ STARTUP ]

Started by the Xfce autostart entry after desktop initialization.

## [ RUNTIME ]

Continue closes the window; the separate browser button starts the selected browser.  
Both actions recheck the required protection state.  
Reads mode-specific protection checks and updates the readiness display.  
Wi-Fi selection is available from the window; Lonewolf can open it automatically when wireless setup is needed.
